Active buffs

Tap skill chips in the team to use them before the Secret Skill. Traits, Guidance and support traits are always on. Set the turn to see effects that start later (e.g. “from turn 6”, “on turn 8”). Turn-limited buffs of the same type don't add up: only the highest counts; permanent ones add on top. Use × to set how many stacks a buff has.
